# make-appointment-vfsglobal

> **Archived / Arşivlendi:** This project is no longer maintained and does not work with the current VFS Global website.

## English

A personal project written in 2022 for the VFS Global Poland visa login page in Turkey (`visa.vfsglobal.com/tur/tr/pol/login`). It is kept here for educational purposes only.

- **It no longer works.** The VFS Global website has changed since this code was written, and no updates are planned.
- **Do not use it to book or resell appointments.** Automating the VFS Global website may violate its terms of use. This also applies to any code derived from this project.
- **Not affiliated with VFS Global.** This project is not affiliated with or endorsed by VFS Global.
- **Never use it with real data.** The code stores personal details, VFS passwords and card details in plain text files.

## Türkçe

2022'de, VFS Global Polonya vize giriş sayfası (`visa.vfsglobal.com/tur/tr/pol/login`) için yazılmış kişisel bir projedir. Sadece eğitim amacıyla burada tutuluyor.

- **Artık çalışmıyor.** Kod yazıldığından beri VFS Global sitesi değişti ve güncelleme planlanmıyor.
- **Randevu almak ya da satmak için kullanmayın.** VFS Global sitesini otomatikleştirmek kullanım şartlarına aykırı olabilir. Bu, projeden türetilen kodlar için de geçerlidir.
- **VFS Global ile bağlantısı yoktur.** Bu proje VFS Global'e ait değildir ve VFS Global tarafından desteklenmez.
- **Gerçek verilerle kesinlikle kullanmayın.** Kod kişisel bilgileri, VFS şifrelerini ve kart bilgilerini düz metin dosyalarda saklar.
